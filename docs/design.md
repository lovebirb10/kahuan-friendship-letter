# 友情来信 · 设计约定

参考：用户提供的海盐风配色图片。视觉概念通过内置 Image Gen 生成，已保存于本地 `.design/concept.png`（不随网站发布）。

设计方向：一封关于友情的信。桌面端左侧大标题、右侧两封重叠的蓝黄信封；问答采用窄版阅读区域与六行选项；结果以回信与六个维度呈现。导航仅含品牌和测试说明。

## 颜色与排版

- 背景：`#edf8ff` 浅海盐蓝桌面，主体信纸为纯白 `#ffffff`。
- 信封与进度：`#88cefa` 海盐蓝（参考图片的实际蓝色区域）。
- 第二封信与胶带：`#fff9aa` 浅柠檬黄。
- 线条：`#c1e2f6` 浅蓝，分隔线采用虚线。
- 主文字：`#294f68` 蓝色墨水，为浅色底提供可读性。
- 原图标注的 `#a1ccd1`、`#e9b384` 作为辅助参考，未用在主要文字上。
- 标题、品牌、主要按钮为中文衬线字体系统栈；正文和表单为微软雅黑／苹方系统栈，不依赖外部字体 CDN。
- 内容最大宽度 1200px；问答 760px；手机断点 600px。

## 首屏文案清单

品牌“卡黄 · 友情来信”；导航“测试说明”；标题“如果是你，会怎样靠近？”；说明“18 个友情情境，遇见你在关系里的样子。”；按钮“开始这封来信 →”；辅助“约 3–5 分钟 · 没有标准答案”；步骤“01 代入情境 / 02 跟随直觉 / 03 收到回信”。恢复进度时按钮与辅助文字按照真实进度变化。

## 实现约束与响应式

所有文案、按钮与计分均为原生 HTML/CSS/JS。信封是 CSS 几何形状，曲线为装饰 SVG，不引入人物照片。没有图像蒙版、色彩覆盖或依赖外链的素材。

手机首页将信封移动到正文下方；结果在窄屏取消大幅装饰，保留可读性。衬线字形因系统字体存在差异。设计稿是多屏概念板，实现在真实浏览器中移除概念板的窗口边框与手机外框，增加实际产品必需的进度、说明、复核和结果解释。

## 交互

首页 → 18 道情境 → 答题复核 → 结果。支持返回修改、答题进度跳转、当前设备自动保存、文字回信下载、重新测试、清除本机进度。键盘使用原生单选按钮与明确焦点样式，支持减少动态效果的系统偏好。
