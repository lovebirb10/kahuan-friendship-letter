# 卡黄 · 友情来信 💌

一份以卡黄相处经历为创作灵感的友情情境娱乐测试。假如你和朋友经历相似的亲近、落差与告别，你会做出什么选择？用 18 次直觉作答，收到一封属于你的友情回信。

**[在线体验](https://lovebirb10.github.io/kahuan-friendship-letter/)**

## 玩法与功能

- 18 道情境题，每题 6 个选项，约需 3–5 分钟。
- 六幕依次为初识、亲密、落差、冲突、告别和后来。
- 支持自动保存本机进度、继续作答、返回修改和答题复核。
- 完成后展示人格结果、三类选择比例、六幕反应与完整回信。
- 支持下载文字回信、重新测试和清除本机进度。

## 三种回信

| 结果 | 内容方向 |
| --- | --- |
| 婷婷桑型人格 | 婷婷桑特点的性格解读与感情相处方式 |
| 发卡型人格 | 发卡特点的性格解读与感情相处方式 |
| 李婷爱型人格 | 结合两者特点的卡黄“赛博长女” |

每封回信包含性格特点、感情相处方式、友情名场面、破防开关和一句赠言。题目与结果采用创作者定稿文案，呈现鲜明、有情绪的同人娱乐表达。

## 计分方式

每题的 6 个选项分别对应婷婷桑、发卡、交织三类，每类各 2 项。人物后缀不在页面展示；选项逐题打乱后固定顺序，刷新、续答和修改答案均保留对应关系。

每选一项，为对应类别加 1 票。完成 18 题后：

- 唯一最高票为婷婷桑或发卡时，获得对应人格。
- 交织类唯一最高票时，获得李婷爱型人格。
- 最高票并列时，获得李婷爱型人格，并在页面说明并列原因。

百分比按三类实际票数计算，使用最大余数法补齐为 100%。交织票独立累计。六幕滑块以婷婷桑为左端、发卡为右端、交织为中点，只展示该阶段的平均反应，不参与额外计分。

## 海盐信笺设计

浅海盐蓝背景搭配白色信纸，用淡黄色胶带、邮票、横线信笺与落款便签延续“友情来信”主题。界面适配电脑和手机。

结果百分比条与图例使用以下展示配色：

| 类别 | 应援色方向 | 界面色值 |
| --- | --- | --- |
| 婷婷桑 | 柠檬黄 | `#f4df45` |
| 发卡 | 破晓红 | `#f06464` |
| 李婷爱／卡黄 | 橙色 | `#ffa34d` |

首页保留小海豹抬尾轻蹭企鹅脸颊的像素风动画：前 2 秒完成动作，随后停留复位，2.8 秒循环。支持暂停与系统减少动态效果设置。

## 本地运行

使用 Node.js 与 npm：

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:4173>。

```bash
npm test
```

测试覆盖题库结构、三种结果、票数分布与百分比、并列判定，以及不完整或无效输入。

## GitHub Pages 部署

网站是原生 HTML、CSS、JavaScript 静态应用，无需构建步骤。GitHub Pages 发布源为 **`main` 分支根目录 `/`**，`.nojekyll` 保证按静态文件发布。

将修改提交并推送至 `main` 后，等待 Pages 发布完成即可。修改样式或脚本时，同步更新入口资源的版本查询参数，方便浏览器获取新版。

## 本机数据

答题进度保存在当前浏览器的 `localStorage`，不上传答案，不接入统计服务。清除浏览器数据或使用页面中的“清除本机进度”会删除保存的进度；不同设备和浏览器之间不自动同步。
