# 卡黄友情选择测试

基于卡黄的经历，设计一份约 24 道题的友情情境测试：**如果你和朋友经历了类似的事情，你会怎么选择？你的相处方式更像婷婷桑，还是更像发卡？**

## 项目想法

先由 AI 阅读和分析卡黄时间线，再把其中有代表性的经历改编成普通人也能代入的友情情境。用户根据自己的真实想法作答，最后获得一份关于友情相处方式的结果。

形式类似人格测试，重点是选择背后的相处倾向，而不是考察用户对卡黄故事的了解程度。

## 素材来源

- 时间线网站：[卡黄时间线](https://kh2322.com/?dt_dapp=1)
- 分析对象：时间线中呈现的事件、互动、关系变化，以及面对分歧时的选择。
- 分析时记录事件时间、原文出处和可确认的行为；将事实、站点解读和 AI 推测分开。
- 婷婷桑、发卡与网站人物的对应关系，需要在阅读素材时核实。

当前进度：已读取原站 2013—2026 年 758 条记录，完成 24 道题及静态网站。网页版阅读工具访问失败后，通过网页公开源码及其引用的年度数据读取材料。未逐一核验全部原始视频和社交平台原帖；题目是创作性的友情情境，不代表真实人物的完整性格。

网站采用文件夹中配色图的奶油底色、海盐蓝和柠檬黄，设计为“友情来信”。素材取舍见 [研究笔记](docs/research.md)，视觉约定见 [设计说明](docs/design.md)。

## 制作流程

### 1. 分析时间线

梳理关键事件及其前因后果，关注双方在沟通、陪伴、表达、矛盾与关系变化中的具体行为。

为每个候选事件记录：

| 字段 | 内容 |
| --- | --- |
| 时间与出处 | 事件日期、来源链接或原文位置 |
| 事件摘要 | 实际发生了什么，哪些信息尚不明确 |
| 双方行为 | 各自做出了什么可以确认的选择 |
| 友情议题 | 该事件可以转化成什么相处问题 |
| 改编方向 | 如何去除背景门槛，变成日常友情情境 |

避免根据孤立片段揣测内心，也不把争议叙述当作确定事实。

### 2. 设计约 24 道友情情境题

每道题围绕一个具体情境展开，核心句式是：

> 假设你和朋友遇到类似的事情，你会怎么做？

题目要求：

- 用户不了解卡黄也能理解、作答。
- 从具体经历中提炼情境，避免只写泛泛的性格问题。
- 每题提供 3—4 个合理选项，让不同相处方式都有可代入的动机。
- 不直接在选项中标出人物名字，避免用户按期待结果作答。
- 避免把选项写成明显的对错题，或将某一方固定塑造成更好的人。
- 涉及原素材的题目保留内部出处，方便复核；前台文案使用自然的日常语言。

可考虑的主题包括主动联系、表达在意、陪伴需求、冲突处理、个人边界和关系变化；最终主题及题量分配由时间线分析决定。

**题型示意（仅说明形式，不对应已核实事件）：**

> 你发现曾经每天聊天的朋友最近回复越来越少，但见面时依然很亲近。你更可能怎么做？
>
> A. 主动问问对方最近的状态，也说出自己的感受。
>
> B. 继续分享日常，让对方有空时再回复。
>
> C. 暂时减少联系，给彼此留些空间。
>
> D. 约一次见面，通过一起相处了解彼此的近况。

### 3. 设计计分与结果

先根据素材建立婷婷桑和发卡在不同情境下的行为画像，再确定选项与画像的对应关系，不能预设谁更主动、谁更克制。

- 用多个友情维度累计倾向，避免由单道题决定结果。
- 允许混合型结果；分数接近时，说明用户在不同情境下呈现不同倾向。
- 结果以“在这份测试的情境中，你的选择更接近……”来表达。
- 如展示相似度，应说明它来自本测试的选项计分，不是科学人格测量或真实人物心理判断。

结果页建议包含：

1. 更接近婷婷桑、发卡，或两者兼具的结果。
2. 一段有共鸣的友情相处方式描述。
3. 用户在表达、沟通、边界等维度上的倾向。
4. 这种相处方式的优点，以及可能产生误会的地方。
5. 一条温和、具体的友情相处建议。

## 用户体验草案

进入测试介绍 → 阅读情境并选择答案 → 查看进度并可返回修改 → 提交答案 → 获得友情倾向结果。

整体语气亲近、有代入感，允许复杂和矛盾的选择。测试不评价谁更值得被爱，也不替真实人物定义完整性格。
