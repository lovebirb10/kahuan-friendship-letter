# 卡黄 · 友情来信

线上网站：https://lovebirb10.github.io/kahuan-friendship-letter/

当前版本采用创作者定稿的 **18 道题、每题 6 个选项**，正文保留；去除人物后缀，逐题打乱选项。正式展示稿见《题库_正式展示版.md》。原稿与候选稿仅留本地，不作为部署内容。

每个选项有固定 ID 和独立类别，隐藏标记不等于删除计分依据。各题的打乱顺序固定，刷新、续答或返回修改不会改变答案对应关系。旧 24 题使用不同存储键，不混用旧进度。

## 计分

婷婷桑、发卡、交织独立累计，各选项为本类加 1 票。18 票中最高票决定结果，最高票并列归为交织型并明确说明。三类比例根据实际票数计算，使用最大余数法补齐 100%，交织票不会拆成两端各半。六幕滑块只描述该阶段的淡／浓反应，不额外计分；三种结果均为同人娱乐创作。

完整说明见 [研究与计分笔记](docs/research.md)。

## 本地运行

运行 `npm run dev`，打开 http://127.0.0.1:4173 。运行 `npm test` 检查计分。静态网站本身无后端，不收集答题数据。

Pages 发布源为 main 根目录。界面沿用奶油底、海盐蓝与柠檬黄配色；支持本机续答、修改答案、复核、文字回信下载与清除进度。
